# District 1 Climate Action Research Website
A data-driven dashboard comparing climate action across four Alameda County District 1 cities: Dublin, Fremont, Livermore, and Pleasanton.

## Description
Toos and Languages Used: React, JavaScript, Python, FastAPI, HTML/CSS, Render
Data & Visualization: Pandas, Matplotlib, Folium

The project evaluates cities across five climate metrics:
-GHG emissions
-Climate Action Plan (CAP) quality
-Heat pump adoption
-EV infrastructure progress
-Tree canopy coverage

The metrics are normalized and ranked to produce an overall index that categorizes cities as Leading, Moderate, or Lagging.

## Features
- City-level climate metric comparisons
- Rankings
- Performance heatmap
- GHG emissions analysis
- Heat pump adoption analysis
- EV infrastructure progress
- Tree canopy coverage comparisons
- Climate Action Plan analysis
- Interactive city map
